Пользовательская документация

Версия: 0,1

Сервис анализирует сайт и конкурентов на основе данных Яндекс.Метрики, скриншотов и текста страниц.

1. Инструмент «Аудит сайта»

Доступны режимы:

  • Аудит по ссылке — анализ одной страницы по скриншотам и тексту.
  • Аудит по выгрузке — загрузка Excel-выгрузок Метрики + аудит топовых страниц.
  • Аудит по Метрике — данные из API Метрики + аудит страниц.

Результат: структурированный отчёт с саммари, проблемами UX, картой соответствия интентов и планом работ.

2. Инструмент «Анализ конкурентов»

На вход подаётся список URL конкурентов. Сервис собирает:

  • скриншоты desktop/mobile;
  • текст страниц;
  • аналитику по структуре и смыслам.

Результат во вкладках:

  • Общие выводы;
  • Нормализованные блоки;
  • Анализ смыслов.

Экспорт в таблицы доступен как встроенная функция инструмента после завершения анализа.

В таблице для этого инструмента формируются листы сравнительного анализа и структуры сайтов.

3. Инструмент «Структура по конкурентам»

Режимы запуска:

  • Структура по топ-10 — сбор URL из выдачи по запросам/региону.
  • Структура по списку сайтов — ручной список URL без сбора топ-10.

Результат:

  • общие выводы;
  • нормализованные блоки;
  • предложение по оптимальной структуре страницы.

Экспорт в таблицы встроен в инструмент и формирует 3 листа:

  • compare — матрица блоков по сайтам;
  • sites — структура каждого сайта по колонкам;
  • structure — предложенная структура (блок + комментарий).
